Solar Charge Africa - Site Plan

WDD 131

Site Name

Name: Solar Charge Africa

Reason for Name: The name clearly describes the primary mission: powering electric mobility across Africa using clean, off-grid solar energy infrastructure.

Site Purpose

The purpose of this site is to educate commercial transport operators, fleet managers, and EV manufacturers on off-grid solar charging and rapid battery-swapping solutions across Sub-Saharan Africa. It provides interactive tools such as fuel savings calculators and a charging hub directory to accelerate clean energy transition.

Scenarios

  • Scenario 1: "How much money can I save per day on operational costs if I switch my commercial tricycle fleet from petrol to solar battery swapping?"
  • Scenario 2: "Where can I locate the nearest operational off-grid solar charging and swap hub along my daily driving route?"

Color Scheme

The following colors are defined and applied throughout this site plan document:

  • Primary Color (#F59E0B - Solar Amber): Used for primary buttons, active navigation links, and call-to-action highlights.
  • Secondary Color (#074F37 - Eco Green): Used for headers, section borders, and emphasis elements representing clean energy.
  • Accent Color (#3B82F6 - Tech Blue): Used for links and interactive hover states.
  • Dark Background (#1F2937 - Charcoal) & Light Background (#F3F4F6 - Light Grey): Used for main text and section container backgrounds.

Typography

The following font families are selected and used across the document:

  • Heading Font ('Segoe UI', Tahoma, Geneva, sans-serif): Applied to all major headings (h1, h2, h3) for a modern, clean look.
  • Body Font (Verdana, sans-serif): Applied to all main body text and paragraphs for optimal readability.
